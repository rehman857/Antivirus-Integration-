# Antivirus-Integration-
This project presents a prototype OS-level Antivirus Monitoring System developed on Kali Linux that integrates traditional antivirus scanning with Blue Team monitoring capabilities.

The system combines:

Signature-based malware detection using ClamAV

File Integrity Monitoring (FIM)

Process activity monitoring

Network connection monitoring

Real-time alert logging

A Blue Team dashboard for visualization

The objective is to simulate a lightweight endpoint detection and response (EDR)-style system for academic and learning purposes.
